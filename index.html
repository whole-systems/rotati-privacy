Rotati privacy policy

Effective date: 24 November 2026

Rotati is a Chrome extension. It notices PDFs and images that are sideways or upside down and turns them upright. This page says what Rotati reads, what it sends and what it stores. "We" means the publisher of Rotati.

Rotati does its work on your device. We run no server, and Rotati sends nothing to us.

What Rotati reads

  • PDFs you open in Chrome. Rotati shows them in its own built-in viewer.
  • Images you open in their own tab.
  • Images inside web pages, but only if you turn on "Check images inside web pages" in Rotati's options. This option is off when you install Rotati. With it on, Rotati checks the larger images on a page as they scroll into view.

Rotati reads these for one reason, to tell whether they are sideways or upside down. It does not read the text of web pages or anything you type into them.

Chrome loads Rotati's code on every page, so that Rotati is ready when you open an image or choose "Save image upright". On an ordinary web page with the option off, that code checks no images.

Click the Rotati button in Chrome's toolbar to turn Rotati off. While it is off, Rotati checks no PDFs or images. PDFs still open in Rotati's viewer.

Where the work happens

Rotati checks and turns everything on your device. It judges which way up a page or picture is with two small programs called models. Both models come inside the extension. Rotati downloads no models and no code after you install it.

What Rotati sends over the internet

We have no server. Rotati sends no data to us or to any third party. It has no analytics, no usage reports, no ads, no accounts and no tracking.

Rotati makes one kind of request over the internet. Sometimes Rotati cannot read an image directly from the page that shows it. This happens with some images that a page loads from another website. Rotati then asks for the same image again from the website that hosts it. The request uses the same address the page already loaded. Chrome sends it with your normal cookies for that website. The request goes to that website and nowhere else, and Rotati adds no information to it.

Rotati makes the same request when you choose "Save image upright" on an image from the web. It also makes it when you press Ctrl+S or Cmd+S in an image tab that Rotati has turned. Rotati needs the full-size image to make the upright copy.

What Rotati stores

Rotati stores two settings.

  • Whether Rotati is on or off. Chrome keeps this setting on your device.
  • Whether Rotati checks images inside web pages. Chrome keeps this setting in its synced storage. If you have Chrome Sync on, Google copies this one setting to your other browsers under Google's privacy policy.

Rotati's PDF viewer also remembers your place in the last 20 PDFs you opened. For each one it saves the page you were on, the zoom, the scroll position, the rotation and the layout of the viewer. It saves these under a short code that identifies the file. The code is the PDF's own built-in ID, or a code computed from the first part of the file. It is not the file's name or its address. If you add a signature with the viewer's signature tool, the viewer saves that signature so you can use it again. All of this stays on your device.

Rotati stores nothing else. It stores no files, page content, images, web addresses or browsing history.

While Rotati runs, a hidden background page keeps recent results in memory, so that Rotati does not check the same image twice. Each result is the turn an image needs, kept under the address of that image. The page holds at most 500 results and writes none of them to disk. Chrome closes the page after about a minute without use, which clears that memory. Closing Chrome clears it too.

Removing Rotati from Chrome deletes what it stored on your device.

Files you save

When you save a PDF from Rotati's viewer, Rotati makes a copy on your device with the pages turned the way you see them. "Save image upright" does the same for an image. Chrome saves the copy as a normal download. Rotati never changes the original file, whether it is on a website or on your disk.

Permissions

Rotati asks Chrome for these permissions. Each one has a single purpose.

  • offscreen lets Rotati run its models for images in one hidden background page, not once in every tab.
  • storage holds the two settings described above.
  • contextMenus adds "Save image upright" to the menu that opens when you right-click an image.
  • Access to all websites. A PDF or an image can come from any site, so Rotati cannot list the sites in advance. Rotati uses this access only in the ways this page describes.

No selling or sharing

We do not sell your data. We do not share it with anyone or transfer it to anyone. We never receive it, so we cannot read it.

Rotati uses what it reads for one purpose, which is to turn PDFs and images upright. It does not use it for advertising or for anything else. Rotati's use of data complies with the Chrome Web Store User Data Policy, including the Limited Use requirements.

Changes to this policy

If we change this policy, we will publish the new version on this page with a new effective date.
